# Chapter 12: Plotting

Symplex can visualize expressions without any external dependencies. The plotting API generates ASCII art for the terminal, SVG for the web, TikZ for LaTeX documents, and raw data for custom pipelines. All of it is driven by a domain-aware sampler that automatically detects singularities and high-frequency oscillations.

## Quick Start: ASCII Plots

The fastest way to see what a function looks like is `.textplot()`:

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

let plot = x.sin().textplot(&x, 0.0, 6.28);
println!("{plot}");
```

This prints something like:

```text
  1.00 |            ***
       |          **   **
       |        **       **
  0.50 |      **           *
       |    **              **
       |  **                  *
  0.00 |**                     **                              **
       |                         *                           **
       |                          **                       **
 -0.50 |                            *                    **
       |                             **                **
       |                               **            **
 -1.00 |                                 ***      ***
       +--+--------+--------+--------+--------+--------+--
       0.00     1.26     2.51     3.77     5.03     6.28
```

The three arguments to `.textplot()` are the variable, the left endpoint, and the right endpoint. The renderer picks sensible Y-axis bounds automatically.

### When ASCII Plots Shine

ASCII plots are ideal for:

- **REPL/interactive exploration** — see the shape of a function without leaving the terminal
- **CI logs** — embed a quick visual sanity check in test output
- **SSH sessions** — no X11 forwarding needed

## SVG Output

For publication-quality or web-embeddable plots, use `.to_svg()`:

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

let svg = x.sin().to_svg(&x, 0.0, 6.28);
println!("{}", &svg[..40]); // <svg xmlns="http://www.w3.org/2000/...
```

The returned string is a complete, self-contained SVG document. It includes:

- Axis lines with tick marks and numeric labels
- Grid lines for readability
- The function curve rendered as a `<polyline>`
- Automatic axis scaling based on the data range

### Saving to a File

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

let f = expr!(x^2 * sin(x));
let svg = f.to_svg(&x, -6.28, 6.28);
std::fs::write("plot.svg", &svg).unwrap();
// Open plot.svg in any browser or SVG viewer
```

### Embedding in HTML

Since the output is a self-contained SVG string, you can drop it directly into an HTML page:

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

let svg = x.sin().to_svg(&x, 0.0, 6.28);

let html = format!(r#"<!DOCTYPE html>
<html>
<head><title>symplex plot</title></head>
<body>
<h1>Plot of sin(x)</h1>
{svg}
</body>
</html>"#);

std::fs::write("plot.html", &html).unwrap();
```

No JavaScript. No external dependencies. Just inline SVG.

## TikZ Output for LaTeX

If you're writing a paper or report in LaTeX, `.to_tikz()` generates a complete `tikzpicture` environment with PGFplots coordinate data:

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

let tikz = x.sin().to_tikz(&x, 0.0, 6.28);
println!("{}", &tikz[..30]); // \begin{tikzpicture}...
```

The output looks something like:

```text
\begin{tikzpicture}
\begin{axis}[
    xlabel={x},
    ylabel={y},
    grid=major,
]
\addplot[smooth, thick, blue] coordinates {
    (0.000, 0.000)
    (0.031, 0.031)
    ...
    (6.280, -0.003)
};
\addlegendentry{f(x)}
\end{axis}
\end{tikzpicture}
```

### Including in a LaTeX Document

Save the TikZ code to a file and `\input` it, or paste it directly:

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

let f = expr!(x^3 - 3*x^2 + 2*x);
let tikz = f.to_tikz(&x, -1.0, 4.0);

let latex = format!(r#"\documentclass{{article}}
\usepackage{{pgfplots}}
\pgfplotsset{{compat=1.18}}
\begin{{document}}
\section{{Plot of $x^3 - 3x^2 + 2x$}}
\begin{{figure}}[h]
\centering
{tikz}
\caption{{Generated by symplex}}
\end{{figure}}
\end{{document}}"#);

std::fs::write("plot.tex", &latex).unwrap();
// Compile with: pdflatex plot.tex
```

Make sure your LaTeX preamble includes `\usepackage{pgfplots}`.

## Raw Data: `plot_data`

If you need the raw `(x, y)` sample points — for feeding into a custom plotting library, exporting to CSV, or doing further numerical analysis — use `.plot_data()`:

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

let data = x.sin().plot_data(&x, 0.0, 6.28, 100);
assert_eq!(data.len(), 100);

// Each element is an (f64, f64) tuple
let (x_val, y_val) = data[0];
println!("x = {x_val:.4}, sin(x) = {y_val:.4}"); // x = 0.0000, sin(x) = 0.0000
```

The four arguments are: variable, left endpoint, right endpoint, and number of sample points. Points are uniformly spaced.

### Feeding into Other Libraries

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

let data = expr!(exp(-x/5) * sin(x)).plot_data(&x, 0.0, 20.0, 500);

// Export as CSV manually
let csv: String = data.iter()
    .map(|(x, y)| format!("{x},{y}"))
    .collect::<Vec<_>>()
    .join("\n");
std::fs::write("damped_sine.csv", &csv).unwrap();
```

## Evaluation Tables: `eval_table`

For structured tabular data with headers and multiple export formats, use `.eval_table()`:

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

let f = x.powi(2);
let table = f.eval_table(&x, &[0.0, 0.5, 1.0, 1.5, 2.0]);
assert_eq!(table.nrows(), 5);
```

The `DataTable` returned by `eval_table` supports several export formats:

### CSV Export

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

let table = x.sin().eval_table(&x, &[0.0, 1.0, 2.0, 3.0]);
let csv = table.to_csv();
println!("{csv}");
// x,f(x)
// 0,0
// 1,0.8414709848078965
// 2,0.9092974268256817
// 3,0.1411200080598672
```

### JSON Export

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

let table = x.powi(2).eval_table(&x, &[1.0, 2.0, 3.0]);
let json = table.to_json();
println!("{json}");
// [
//   {"x": 1, "f(x)": 1},
//   {"x": 2, "f(x)": 4},
//   {"x": 3, "f(x)": 9}
// ]
```

### Markdown Export

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

let table = x.powi(3).eval_table(&x, &[0.0, 1.0, 2.0, 3.0]);
let md = table.to_markdown();
println!("{md}");
// | x   | f(x) |
// |-----|------|
// | 0   | 0    |
// | 1   | 1    |
// | 2   | 8    |
// | 3   | 27   |
```

## Domain-Aware Sampling

Under the hood, `.textplot()`, `.to_svg()`, and `.to_tikz()` don't just evaluate on a uniform grid. They use a **domain-aware adaptive sampler** that:

1. **Finds singularities** — calls the internal `singularities()` analysis to detect points where the function blows up (e.g., `1/x` at `x = 0`, `tan(x)` at `x = π/2`). These points are excluded from the sample so they don't distort the axis scaling.

2. **Estimates frequency** — calls `estimate_frequency()` to detect high-frequency oscillations. If your function is `sin(100*x)`, the sampler knows it needs more points than for `sin(x)`.

3. **Compiles for speed** — the expression is compiled to a native closure via `.compile()` before sampling. No expression-tree walking during the sample loop.

This means you can plot functions with poles and discontinuities without manual intervention:

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

// 1/x has a singularity at x = 0
// The plotter detects it and samples around it
let plot = (symplex::int(1) / &x).textplot(&x, -5.0, 5.0);
println!("{plot}");

// tan(x) has singularities at ±π/2, ±3π/2, ...
let plot = x.tan().textplot(&x, -6.0, 6.0);
println!("{plot}");
```

Points where the function produces `NaN` or `±∞` are rendered as gaps in the curve rather than wild spikes.

## Comparing Multiple Functions

To plot two functions on the same axes, you can generate SVG manually using the raw data:

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

let sin_data = x.sin().plot_data(&x, 0.0, 6.28, 200);
let cos_data = x.cos().plot_data(&x, 0.0, 6.28, 200);

// Both data sets share the same x range, so you can
// combine them into a single CSV for external plotting:
let mut csv = String::from("x,sin(x),cos(x)\n");
for i in 0..sin_data.len() {
    let (xv, sy) = sin_data[i];
    let (_, cy) = cos_data[i];
    csv.push_str(&format!("{xv},{sy},{cy}\n"));
}
std::fs::write("sin_cos.csv", &csv).unwrap();
```

For terminal comparison, generate textplots side by side:

```rust
use symplex::prelude::*;
use symplex::vars;

vars!(x);

println!("sin(x):");
println!("{}", x.sin().textplot(&x, 0.0, 6.28));

println!("\ncos(x):");
println!("{}", x.cos().textplot(&x, 0.0, 6.28));
```

## Full Workflow: Derive, Plot, Export

Here's a complete example that derives a function, finds its critical points, and plots everything:

```rust
use symplex::prelude::*;
use symplex::vars;

fn main() {
    vars!(x);

    // Define and differentiate
    let f = expr!(x^3 - 3*x^2 + 2*x);
    let df = f.diff(&x);

    // Find critical points
    let critical = df.solve_or_empty(&x);
    println!("f(x)  = {f}");
    println!("f'(x) = {df}");
    for pt in &critical {
        println!("Critical point: x = {pt}");
    }

    // ASCII plot for quick inspection
    println!("\nf(x):");
    println!("{}", f.textplot(&x, -1.0, 4.0));

    println!("f'(x):");
    println!("{}", df.textplot(&x, -1.0, 4.0));

    // SVG for sharing
    let svg = f.to_svg(&x, -1.0, 4.0);
    std::fs::write("cubic.svg", &svg).unwrap();

    // TikZ for the paper
    let tikz = f.to_tikz(&x, -1.0, 4.0);
    std::fs::write("cubic.tikz", &tikz).unwrap();

    // Data table for numerical analysis
    let table = f.eval_table(&x, &[-1.0, 0.0, 0.5, 1.0, 1.5, 2.0, 3.0, 4.0]);
    std::fs::write("cubic.csv", table.to_csv()).unwrap();
    println!("\nData table:\n{}", table.to_markdown());
}
```

## What's Next

The current plotting API covers the common 2D single-variable case well. Here's what's planned for future versions:

- **Bode plots** — `tf.bode_svg()` for control-systems transfer functions, showing magnitude and phase vs. frequency
- **Phase portraits** — vector field visualization with fixed-point markers for ODE systems
- **Step/impulse response** — time-domain plots for control systems
- **Parametric plots** — curves defined by `(x(t), y(t))` over a parameter range
- **Implicit plots** — shade regions where `f(x, y) > 0` or plot level curves `f(x, y) = c`
- **3D surface plots** — wireframe or shaded surfaces for `z = f(x, y)`
- **Interactive WASM visualization** — compile symplex to WebAssembly and render interactive plots in the browser with pan/zoom

For now, the combination of textplot, SVG, TikZ, and raw data export covers the vast majority of workflows. Head to [Chapter 17: Advanced Expression Manipulation](17-advanced-manipulation.md) to learn how to inspect, walk, and transform expression trees.
